# Free_OCR

一个基于 **Flask + RapidOCR + HTML5 Canvas** 的图片 OCR 模板识别网页应用。

项目面向“同类型图片重复识别”的场景：用户首次导入图片后，可以创建多个识别区域，为每个区域指定名称和 OCR 类型并保存为模板；后续导入同类型图片时，选择已有模板即可自动恢复识别区域并立即进行 OCR。

项目同时提供图片整体调整能力，用于解决新图片与模板之间存在轻微位置、角度、尺寸或方向偏差的问题。调整图片时，识别框保持不变，用户可以通过拖动、缩放、旋转和镜像图片，让图片内容重新对准模板区域。

## 项目特点

### 1. 基于模板的重复图片识别

第一次处理某一类图片时，可以创建模板并保存识别区域。

例如身份证图片：

```text
姓名
性别
民族
出生
住址
身份证号码
```

这些区域保存以后，再上传同类型图片，只需要选择对应模板，系统就会自动恢复区域并开始识别。

---

### 2. 一个图片可以创建多个识别区域

用户可以在图片上多次框选区域。

每个区域具有：

- 区域名称
- OCR 识别类型
- 位置
- 宽度
- 高度

坐标和尺寸不会直接显示在右侧识别结果中，而是作为区域内部数据保存。

---

### 3. 保存区域后立即 OCR

创建一个识别区域并点击“保存区域”以后，系统会立即对当前区域进行 OCR。

因此不需要：

```text
框选区域1
↓
框选区域2
↓
框选区域3
↓
全部完成
↓
最后统一 OCR
```

而是：

```text
框选区域1
↓
保存区域
↓
立即 OCR
↓
显示结果
```

这样可以减少等待时间，也方便用户边创建区域边确认识别效果。

---

### 4. 模板套用后自动 OCR

选择已有模板并上传对应图片后：

```text
选择模板
↓
上传图片
↓
恢复模板区域
↓
自动 OCR
↓
右侧直接显示识别结果
```

不需要再手动点击“开始 OCR”。

---

### 5. 多区域并行 OCR

后端使用线程池处理多个识别区域。

默认最大并发数量：

```python
OCR_MAX_WORKERS = 4
```

也就是说，一张图片存在多个识别区域时，不再完全按照：

```text
区域1 → 区域2 → 区域3 → 区域4
```

串行等待，而是使用最多 4 个 OCR 工作线程并行处理。

每个线程使用自己的 RapidOCR 实例，避免多个线程直接共享同一个 OCR 引擎。

---

### 6. 图片整体调整

套用模板时，如果新图片与模板区域存在偏差，不需要逐个修改识别框。

可以保持红框不动，直接调整整张图片：

- 放大
- 缩小
- 90° 逆时针旋转
- 90° 顺时针旋转
- -15° ～ +15° 精细旋转
- 精细旋转最小步进 0.1°
- 左右镜像
- 上下镜像
- 图片拖动
- 重置调整
- 应用调整

图片调整工具栏位于图片下方，并采用图标化、无边框的工具按钮。

# 功能说明

## 一、模板工作模式

系统有三种状态：

```text
none      未选择工作模式
new       新建模板
existing  使用已有模板
```

### 初始状态

打开网页后：

```text
新建模板
```

此时还不能直接上传图片。

如果直接点击“上传图片”，系统会提示：

```text
请先点击“新建模板”或选择已有模板，再上传图片
```

这样可以避免用户在没有明确模板归属的情况下直接创建识别区域。

---

## 二、新建模板

点击：

```text
新建模板
```

之后：

1. 模板名称输入框显示。
2. 输入模板名称。
3. 上传图片。
4. 创建识别区域。
5. 保存每个识别区域。
6. 确认所有区域都已经保存。
7. 点击“保存当前模板”。

保存模板之前会进行校验。

### 模板名称不能为空

否则提示：

```text
请输入模板名称
```

### 必须先上传图片

否则提示：

```text
请先上传图片
```

### 必须至少存在一个识别区域

否则提示：

```text
请至少创建并保存一个识别区域
```

### 不允许存在未保存区域

如果当前还有蓝色临时区域没有保存：

```text
请先保存当前识别区域，再保存模板
```

### 图片调整必须先应用

如果图片进行了缩放、旋转、镜像或拖动，但没有点击“应用调整”，保存模板时会提示：

```text
请先点击“应用调整”，再保存模板
```

---

## 三、保存模板后的状态

模板保存成功以后，系统回到初始模板状态：

```text
新建模板
```

不会自动套用刚刚保存的模板。

这样可以避免：

```text
保存模板
↓
旧模板区域继续残留
↓
上传下一张图片时自动套用旧区域
```

的问题。

# OCR 类型

目前支持 7 种 OCR 类型。

| 类型 | 标识 | 说明 |
|---|---|---|
| 纯数字 | `number` | 数字、整数、小数、负数 |
| 纯中文 | `chinese` | 中文字符 |
| 纯英文 | `english` | 英文字母 |
| 中英文混合 | `chinese_english` | 中文 + 英文 |
| 中文 + 数字 | `chinese_number` | 中文 + 数字 |
| 英文 + 数字 | `english_number` | 英文 + 数字 |
| 中英文 + 数字 | `chinese_english_number` | 中文 + 英文 + 数字 |

---

## 纯数字过滤

纯数字类型会自动：

- 转换全角数字为半角数字
- 保留数字
- 保留小数点
- 保留负号
- 删除其他字符
- 最多保留一个小数点
- 负号只允许出现在开头

例如：

```text
１２３．４５
```

会转换为：

```text
123.45
```

# 模板系统

## 模板保存的数据

模板不会直接保存固定像素坐标，而是保存区域相对于模板图片尺寸的比例：

```text
x_ratio
y_ratio
width_ratio
height_ratio
```

例如：

```text
x_ratio = x / image_width
y_ratio = y / image_height
width_ratio = width / image_width
height_ratio = height / image_height
```

这样在模板图片尺寸与后续上传图片尺寸不同的情况下，可以按照比例恢复识别区域。

---

## 使用已有模板

在“已有模板”下拉框中选择模板。

模板选中以后：

- 模板名称显示
- 模板工作模式切换为 `existing`
- 上传图片
- 图片加载完成后自动恢复模板区域
- 自动开始 OCR

如果模板中有 6 个区域，则右侧会显示 6 个识别结果。

---

## 模板删除

选择已有模板后点击：

```text
删除模板
```

系统会弹出确认框。

确认后删除模板 JSON 文件。

删除成功以后：

```text
templateMode = none
```

并恢复到初始状态。


范围：

```text
-15° ~ +15°
```

```text
0.1°
```

图片拖动模式不是默认开启的。

必须先点击：

```text

```

进入图片拖动模式。

然后：

1. 鼠标移动到图片上。
2. 按住鼠标左键。
3. 拖动图片。
4. 松开鼠标。

再次点击：

第一次开始图片调整时，会提示：


```text

结束当前图片调整状态
```

# OCR 处理机制

OCR 后端位于：

```text
services/ocr_service.py
```

处理流程：

```text
上传图片
    ↓
保存到 data/uploads
    ↓
获取识别区域
    ↓
读取原始图片
    ↓
按照区域坐标裁剪
    ↓
区域放大 2 倍
    ↓
Auto Contrast
    ↓
RapidOCR
    ↓
合并 OCR 文本
    ↓
按照 OCR 类型过滤
    ↓
计算平均置信度
    ↓
返回 JSON
```

---

## 区域预处理

每个识别区域：

1. 从图片中裁剪。
2. 转换为 RGB。
3. 放大 2 倍。
4. 使用 `ImageOps.autocontrast()` 增强对比度。
5. 转换为 NumPy 数组。
6. 交给 RapidOCR。

---

## OCR 并行

后端使用：

```python
ThreadPoolExecutor
```

默认：

```python
OCR_MAX_WORKERS = 4
```

OCR 引擎使用线程本地存储：

```python
threading.local()
```

每个工作线程第一次执行 OCR 时创建自己的 RapidOCR 实例，后续复用。

# 模板数据格式

模板 JSON 类似：

```json
{
    "name": "身份证",
    "image_width": 1920,
    "image_height": 1080,
    "areas": [
        {
            "id": 1,
            "name": "姓名",
            "type": "chinese",
            "x_ratio": 0.2,
            "y_ratio": 0.3,
            "width_ratio": 0.1,
            "height_ratio": 0.05
        }
    ],
    "updated_at": "2026-08-17T15:00:00"
}
```

模板重点保存：

```text
区域名称
OCR 类型
区域相对于图片的比例位置
```

而不是固定的像素位置。

# 旧版本数据兼容

`config.py` 中保留了旧目录兼容逻辑。

旧模板目录：

```text
templates_data/
```

旧图片目录：

```text
uploads/
```

启动时，如果发现旧目录存在，会自动把旧模板和图片复制到：

```text
data/templates/
data/uploads/
```

已经存在的目标文件不会重复覆盖。

# 使用注意事项

## 1. 必须先选择模板工作模式

不能：

```text
打开网页
↓
直接上传图片
```

必须先：

```text
新建模板
```

或者：

```text
选择已有模板
```

然后才能上传图片。

---

## 2. 保存模板前必须保存区域

创建蓝色临时框后，如果没有点击“保存区域”，不能直接保存模板。

---

## 3. 图片调整后必须点击应用

如果调整了：

- 缩放
- 旋转
- 镜像
- 拖动

必须点击：

```text
✓ 应用调整
```

系统才会重新 OCR。

---

## 4. 图片调整不会移动识别框

图片调整的设计原则是：

```text
图片可以移动
图片可以旋转
图片可以缩放
图片可以镜像

识别框保持不变
```

主要用于模板套用时修正图片与模板之间的整体偏差。

---

## 5. 图片拖动需要主动开启

图片拖动模式不是默认状态。

必须点击：

```text
↖
```

之后才能按住图片拖动。

再次点击可以退出拖动模式。

---

## 6. OCR 结果是当前图片识别结果

模板保存的是：

```text
识别区域位置
区域名称
OCR 类型
```

不会把某一张图片的 OCR 文字结果作为模板固定内容保存。
